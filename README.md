# Crow Fitness

Crow Fitness is a simple, single-user workout tracker for planning workouts, recording sets, and tracking exercise progress. It is designed for one person, with no authentication or multiple-user support.

## Project status

The project is in the planning stage. The application is not implemented yet; the features and technology stack below describe the intended direction.

## Planned features

- Create reusable workout templates with the exercises you want to perform.
- Start a workout session from a template.
- View previous sets for each exercise and record weight and reps during a session.
- Browse workout history and all recorded sets by exercise to track progress over time.

## Planned technology stack

| Layer | Technology |
| --- | --- |
| Frontend | Next.js with TypeScript |
| Backend | Go REST API |
| Database | PostgreSQL |
